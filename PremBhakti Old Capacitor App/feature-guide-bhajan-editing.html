📖 Bhajan Editing — kaise chalta hai

Admin Panel → Local Data → Bhajans · Sept 2026 ke changes

Ek line mein

Ab bhajan save karte waqt app hamesha cloud ka latest data dekhta hai, sirf phone ki purani copy nahi. Isliye na number duplicate hota hai, na kisi doosre admin ka kaam mit-ta hai.

Bhajan data kahan rehta hai

Firebase Storage ke app-data/bhajandata/ folder mein 3 cheezein:

  • 215.json — har bhajan ki apni file
  • bundle.json — saare bhajan ek saath (users ke phone yahi download karte hain)
  • index.json — list + ek timestamp. Phone ye time dekh ke samajhta hai ki naya bundle lena hai ya nahi

Order hamesha: pehle bhajan file → phir bundle → sabse last index.

1. Bhajans screen kholte hi

App cloud ke index.json ka time phone ke time se milata hai.

  • Same hai → kuch nahi, seedha list.
  • Cloud naya hai → pehle naya data download ("Downloading the latest bhajans…"). Tab tak list aur + Add band.
  • Internet nahi → peeli patti + Retry. Edit kar sakte ho, Save par phir se jaanch hogi.

2. Editor mein song number

  • 72 aur 072 ek hi number maane jaate hain. 100 se chhote number apne aap 072 ban jaate hain (purana format).
  • Number kisi aur bhajan ka hai → laal warning + Save band.
  • Purane bhajan ka number badla → pehle confirm popup (purana number hat jaata hai).
  • + Add agla khaali number local + cloud dono dekh ke deta hai.

3. Save dabane par kya hota hai

1
Lock — Firestore mein app_config/bhajandata_write_lock banta hai. Koi aur admin usi waqt save kar raha ho to: "… is saving right now, try again".
2
Cloud se fresh bundle padha jaata hai (seedha Storage se, CDN se nahi).
3
Jaanch — number kisi aur ka to nahi? Editor kholne ke baad kisi aur ne yahi bhajan badla ya hataya to nahi?
4
Sirf aapka badlav cloud bundle par lagta hai → file, bundle, index likhe jaate hain → phone ki list bhi cloud jaisi ho jaati hai.
5
Lock hat jaata hai.
Step 3 mein kuch bhi galat mila to kuch bhi likha nahi jaata.

4. "Another admin changed this bhajan" popup

Isme cloud wala version dikhta hai. 3 button:

Open the cloud versionUnka version editor mein khulega. Aapke badlav hat jaayenge.
Save mine anywayAapka version save. Unka badlav hat jaayega.
CancelPopup band, editing chalu. Kuch save nahi hua.

Aur chhote changes

  • Preview button (editor ke upar) — bina save kiye bhajan ko asli reading screen par dekho. Sirf dekhne ke liye, Star/Share band.
  • List mein #दोहा# jaisi subheading ki jagah bhajan ki pehli asli line dikhti hai.
  • Author Manager, Filter Category aur Rebuild Bundle bhi isi safe tareeke se save karte hain.
  • Back button: har press ek step peeche (font panel → preview → popup → editor). Save fail hone par ab panel galti se screen peeche nahi jaata.

Yaad rakhne wali baatein

  • App save ke beech band ho gaya to lock 2 minute mein apne aap khul jaata hai.
  • Lock ke liye koi naya Firestore rule nahi chahiye — app_config admins ke liye pehle se khula hai.
Testing mein asli save nahi kiya gaya tha (live data). Ek baar phone se kisi bhajan mein chhota badlav karke save zaroor check karna.
