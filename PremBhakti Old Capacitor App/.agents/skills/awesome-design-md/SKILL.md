# Awesome DESIGN.md

This skill provides a curated collection of DESIGN.md files extracted from real websites. 

To use a specific design:
1. Search the `design-md/` directory in this skill for the desired brand.
2. Read the `DESIGN.md` file located in `design-md/<brand>/DESIGN.md`.
3. Apply the design guidelines to the user's project.
