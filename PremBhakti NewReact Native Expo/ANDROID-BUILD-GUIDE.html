1Sabse pehle — 3 zaroori niyam

Ye teen baatein yaad rahengi to 90% problems kabhi aayengi hi nahi.

🛡️

Asli app ko kuch nahi hoga

Ye app phone par com.cpbs.bhajans.rntest ("Prem Bhakti RN") naam se alag install hoti hai. Play Store wali asli com.cpbs.bhajans aur uska data bilkul safe rehta hai — dono app saath-saath chalti hain.

📁

Sirf C:\rn\mobile

Code aur build dono yahin. Worktree wala lamba path (…\.claude\worktrees\…\mobile) purani copy hai — Windows ki path-length limit ki wajah se wahan C++ build fail hota hai.

⛔

Gradle upgrade mat karna

Android Studio baar-baar "Upgrade Gradle / AGP" bolega. Mana karna hai. React Native 0.86 ko exactly Gradle 9.3.1 aur JDK 17 chahiye — upgrade karte hi build toot jaata hai.

3Ek baar ka setup

Ye sirf pehli baar (ya naya PC / Android Studio reinstall hone par) karna hai.

  1. Project kholo Android Studio → File → Open → ye folder chuno:
    C:\rn\mobile\android
    Kyon android sub-folder? Android Studio ko Gradle project chahiye, jo android folder mein hai. Pura C:\rn\mobile khologe to wo JavaScript project samjhega aur build option nahi dikhenge.
  2. Gradle Sync poora hone do Neeche status bar mein "Gradle sync" chalta dikhega. Pehli baar 5–10 minute lagte hain (libraries download hoti hain). Beech mein Studio band mat karna.
  3. Upgrade wala popup aaye to mana karo "Project update recommended" / "Upgrade Android Gradle Plugin" jaisa popup aaye to Don't ask again for this project dabao.
    Kyon? React Native 0.86 Gradle 9.3.1 ke saath hi test hua hai. Naya Gradle (jaise 9.8) RN ke C++ build ko tod deta hai.
  4. JDK 17 check karo (normally apne-aap set hota hai) File → Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK mein GRADLE_LOCAL_JAVA_HOME (jdk-17) dikhna chahiye. Kuch aur dikhe to list se jdk-17 chuno.
    Kyon? Android Studio ka apna Java (JBR) version 25 hai. Usse build karne par "restricted method in java.lang.System" error aata hai. Project mein JDK 17 ka path pehle se pin kiya hua hai (gradle.properties + .gradle/config.properties), isliye ye step bas confirm karne ke liye hai.
  5. Phone ready karo
    • Phone: Settings → Developer options → USB debugging ON
    • USB cable lagao (data wali cable — sirf charging wali nahi chalegi)
    • Phone par popup "Allow USB debugging?" → Always allow from this computer ✓ → Allow
    • Android Studio ke upar device dropdown mein Samsung SM-M556… (Galaxy M55) dikhne lagega

4Release APK banana (testing ke liye best)

Ye poori, akeli chalne wali app hai — bilkul waisi jaisi user ke phone par chalegi.

  1. Build Variant "release" chuno View → Tool Windows → Build Variants. Ek panel khulega jisme :app ke saamne dropdown hai → release chuno.
    Baaki modules (expo, reanimated wagera) apne-aap match ho jaate hain, unhe chhedne ki zaroorat nahi.
  2. APK generate karo Build → Generate App Bundles or APKs → Generate APKs

    Neeche Build tab mein progress dikhega. Pehli baar 20–30 min (C++ code compile hota hai), baad mein kaafi jaldi.

    ⚠️

    "Generate Signed App Bundle / APK" wala option mat chuno — wo keystore maangega. Testing ke liye simple Generate APKs kaafi hai; project already test key se sign karta hai.

  3. APK dhoondo Build khatam hone par neeche-right popup aayega → locate dabao. Ya seedha yahan:
    C:\rn\mobile\android\app\build\outputs\apk\release\app-release.apk
  4. Phone par install karo — koi bhi ek tareeka:
    • USB se (aasan): phone jude hone par ye file double-click karo —
      C:\rn\mobile\scripts\install-release-on-phone.cmd
      Last mein Success likha aaye to ho gaya.
    • Bina cable: APK ko WhatsApp / Drive / Bluetooth se phone par bhejo → file par tap → Install. ("Unknown apps" ki permission maange to us app ko allow karo.)
    ⚠️

    PC par APK ko double-click mat karnaIs computer par .apk files BlueStacks se khulti hain. Double-click karte hi BlueStacks emulator chalu ho jaata hai aur app usme install ho jaati hai, phone mein nahi. Phone ke liye upar wala script ya file bhejne wala tareeka hi use karo.

  5. Chala kar dekho Phone ke app drawer mein Prem Bhakti RN kholo. Asli Prem Bhakti bhi wahin alag dikhegi — wo bilkul waisi hi hai.
ℹ️

Test APK sirf 64-bit (arm64) phones ke liyeBuild jaldi ho aur APK chhoti bane, isliye test build sirf arm64-v8a ke liye banta hai (Galaxy M55 aur aaj ke lagbhag sab phone). Release build code ko chhota (R8) bhi karta hai. Pehla build ~20–30 minute, uske baad Gradle cache se kaafi jaldi. Roz ke UI kaam ke liye APK ki jagah EXPO-PHONE-GUIDE.html wala tareeka use karo.

5Debug build chalana (code likhte waqt)

Debug app khud mein JavaScript nahi rakhti — wo PC par chal rahe Metro server se code leti hai. Isliye code save karte hi phone par turant badlav dikh jaata hai.

Code file save→Metro (PC, port 8081)→USB (adb reverse)→Phone par app reload
  1. Phone USB se lagao (setup ka step 5 ho chuka ho).
  2. Metro start karo — ye file double-click karo aur window khuli rehne do:
    C:\rn\mobile\scripts\start-metro.cmd
    Ye kya karta hai? Pehle adb reverse tcp:8081 tcp:8081 chalata hai (phone ka "localhost:8081" PC tak pahunch jaata hai), phir npx expo start --dev-client se Metro shuru karta hai. "Waiting on http://localhost:8081" dikhe to ready hai.
  3. Build Variant "debug" chuno Build Variants panel → :app → debug.
  4. Run ▶ dabao Upar device dropdown mein apna phone chuno → hara ▶ Run button (ya Shift+F10). Studio build karke phone par install aur launch kar dega.
  5. Code badlo, result dekho C:\rn\mobile\src\… mein koi bhi file save karo — phone par app 1–2 second mein update. Pura reload chahiye to Metro window mein r dabao.
💡

Debug app ek baar install ho gayi to har baar Studio se Run karne ki zaroorat nahi. Agle din bas start-metro.cmd chalao aur phone par app kholo — wo khud Metro se jud jaayegi. Studio se dobara Run tabhi karna hai jab native cheez badli ho (neeche table dekho).

6Code badalne ke baad kya karna hai?

Badlav kis type ka hai, us hisaab se kaam alag hai.

Kya badlaExampleDebug ke liyeRelease ke liye
Sirf JS / screen / design src/ ki koi .tsx / .ts file Kuch nahi — apne-aap reload Section 4 se dobara APK banao
Naya npm package (JS-only) koi utility library npm install, phir Metro restart npm install → dobara APK
Web screens (Profile, Menu ke web pages, admin) aaaacursor mein OG app ka naya commit npm run web:build → npx expo prebuild → Studio mein Sync Project with Gradle Files → dobara Run / Generate APKs
Native cheez naya native module, app.json, icon, permission, plugin npm install → npx expo prebuild → Studio mein File → Sync Project with Gradle Files → dobara Run / Generate APKs

Commands (C:\rn\mobile folder mein terminal kholkar):

cd /d C:\rn\mobile
npm install
npx expo prebuild
✅

Web screens ka build: npm run web:buildJo screens abhi native nahi bani (Profile ke andar ka hissa, Menu ke Information/Donate/About wagera, admin panel), wo OG app ka hi web code hain, jo APK ke andar rakha jaata hai. Ye command aaaacursor ke aakhri commit ki copy C:\rn\web-src mein banati hai (aaaacursor mein kuch nahi likhti), aur nateeja web-bundle folder mein rakhti hai. Pehli baar 5-10 minute lagte hain, baad mein 1-2 minute. Agar aaaacursor mein bina commit wale badlav hon, to ye saaf warning dikhati hai ki wo bundle mein NAHI gaye. Iske baad npx expo prebuild zaroor chalao, tabhi naya web code APK mein jaata hai.

npm run web:build
✅

npx expo prebuild --clean bhi safe haiYe android folder ko poora naya bana deta hai, lekin plugins/withTestBuild.js har baar ye sab dobara laga deta hai: alag package name (.rntest), app ka naam "Prem Bhakti RN", testing crashes asli app ki Crashlytics mein na jaayein, aur JDK 17 ka pin. plugins/withLocalSdk.js SDK ka path (android/local.properties) bhi apne-aap likh deta hai. Kuch haath se badalna nahi padta.

8Error aaye to kya karein

Error ka message dekho aur neeche match karo. Har ek par click karke solution kholo.

restricted method in java.lang.System / Unsupported class file major version

Wajah

Gradle galat Java (JDK 25 / Studio ka JBR) se chal raha hai.

Solution

Section 3 ka step 4 — Gradle JDK ko jdk-17 par set karo, phir File → Sync Project with Gradle Files. Agar prebuild --clean ke baad hua ho to ek baar dobara npx expo prebuild chala do (plugin JDK pin wapas laga dega).

cmake_pch.hxx … missing / ninja: error / C++ (CXX) build error

Wajah

Purane C++ build ka adhoora cache.

Solution

Studio band karo, ye folder delete karo, phir dobara build:

C:\Users\damod\.rncxx

Fir bhi na chale to C:\rn\mobile\android\app\.cxx aur C:\rn\mobile\android\app\build bhi delete karke build karo.

Filename / path "too long" error, ya CMake path error

Wajah

Galat (lamba) folder khula hai — shayad worktree wala.

Solution

Studio ke title bar mein path dekho. Wo C:\rn\mobile\android hona chahiye. Nahi hai to File → Close Project karke sahi folder kholo.

Debug app khulte hi laal screen: "Unable to load script" / "Could not connect to development server"

Wajah

Metro nahi chal raha, ya phone PC tak nahi pahunch pa raha.

Solution

start-metro.cmd chalao (window khuli rakho). Phone ka cable nikal kar dobara lagaya ho to script dobara chalao — adb reverse har baar cable lagane par chahiye. Phir app mein Reload dabao.

INSTALL_FAILED_UPDATE_INCOMPATIBLE / "App not installed" / signatures do not match

Wajah

Phone par pehle se "Prem Bhakti RN" kisi doosri key se sign hui padi hai.

Solution

Sirf test app hatao (iska data hi jaayega, asli app ka nahi):

"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" uninstall com.cpbs.bhajans.rntest
🚫

Command mein .rntest zaroor ho. com.cpbs.bhajans (bina .rntest) kabhi uninstall mat karna — wo asli Play Store app hai, uska poora data chala jaayega.

Gradle sync / build bahut dheema, ya "Out of memory" / "Java heap space"

Solution

Chrome, emulator aur doosre IDE (Antigravity / VS Code) band karo — Gradle ko RAM chahiye. Release ka pehla build 25 min tak le sakta hai, ye normal hai. Atak jaaye to File → Invalidate Caches… → Invalidate and Restart.

Phone device list mein nahi dikh raha

Solution

Section 7 ki table dekho. Samsung par kabhi-kabhi USB mode "Charging only" ho jaata hai — notification bar se File transfer chuno. Phir bhi nahi to Developer options mein Revoke USB debugging authorizations → cable dobara lagao → Allow.

Studio ne galti se Gradle / AGP upgrade kar diya

Solution

Kuch haath se theek karne ki zaroorat nahi. C:\rn\mobile mein terminal kholo aur chalao — android folder sahi versions ke saath naya ban jaayega:

npx expo prebuild --clean

9Play Store release (abhi nahi — baad mein)

⏳

Ye steps tabhi jab app asli Prem Bhakti ki jagah update ke roop mein jaane ke liye taiyaar ho. Usse pehle kuch mat badlo.

  1. Test plugin hataoapp.json ki plugins list se ["./plugins/withTestBuild", …] wali entry hatao. Isse package wapas com.cpbs.bhajans, naam "Prem Bhakti" aur Crashlytics ON ho jaayega.
  2. Version badhaoapp.json mein version aur android.versionCode — versionCode Play Store par maujood version se bada hona chahiye.
  3. Asli upload key lagaoRelease ko Play Store wali upload key se sign karna hoga (abhi test key lagi hai), aur Build → Generate Signed App Bundle se .aab banana hoga.
  4. Purane data ka migrationPurani app ka data (history, playlists, downloads) nayi app mein aaye — ye kaam release se pehle karna baaki hai.
