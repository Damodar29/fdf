1Ye kya hai

React Native app ka JavaScript browser mein bhi chal sakta hai (react-native-web). Isse koi bhi screen ka design aur kaam PC par hi dekh sakte ho — APK banane ki zaroorat nahi, aur code save karte hi page badal jaata hai.

Code save (src/…)→Metro (port 8081)→Chrome mein app
ℹ️

Do server chalte hain: 8081 par app khud, aur 8090 par OG app ka web build. Jo screens abhi WebView mein hain (Darshan, Donate, Profile wagera) wo browser mein iframe ban kar 8090 se aati hain, aur Hindi font bhi wahi se aata hai.

2Ek baar ka setup

  1. Packages install (sirf pehli baar, ya jab package.json badle):
    cd /d C:\rn\mobile
    npm install
  2. Web screens ka build — web-bundle folder pehle se bana ho to ye step chhod do. OG app ka naya commit aaye tab dobara chalao:
    npm run web:build
    Kyon? WebView wali screens OG app ka hi web code hain. Ye command aaaacursor ke aakhri commit ki copy C:\rn\web-src mein banakar web-bundle mein rakhti hai (aaaacursor mein kuch nahi likhti).

3Roz chalana — 2 terminal

  1. Terminal 1 — web screens ka server. Chalta chhod do:
    cd /d C:\rn\mobile && npm run web:preview
    Ready kab? Jab likha aaye web-bundle preview on http://localhost:8090.
  2. Terminal 2 — app. Chalta chhod do:
    cd /d C:\rn\mobile && npm run web
    Ready kab? "Waiting on http://localhost:8081" dikhe. Pehli baar 1–2 minute lagte hain (bundle banta hai), baad mein kuch second.
  3. Chrome mein kholo:
    http://localhost:8081
  4. Code badlo, result dekho. src/ mein koi file save karo — page apne-aap update. Pura reload: F5.
  5. Band karna: dono terminals mein Ctrl+C.

4Phone jaisa size

  1. Chrome mein F12 dabao (DevTools).
  2. Ctrl+Shift+M — upar device toolbar aa jaayega.
  3. Device list se koi phone chuno (jaise Pixel 7 ya Samsung Galaxy S20), phir F5.
💡

Dark mode dekhna ho to app ki Settings → ऐप का थीम → डार्क chuno — bilkul phone jaisa.

5OG app se milana

Doosre tab mein OG app ka web version kholo aur dono ko saath rakh kar dekho.

http://localhost:8090
  1. "Install app" popup aaye to Not Now dabao.
  2. Dono tabs mein DevTools ka same phone size rakho.
  3. Language aur theme dono mein ek jaisa rakho (OG mein bhi Settings se).

6Kaam ki baatein

🧹 Naye install jaisa

Intro (onboarding) dobara dekhna ho: F12 → Console mein localStorage.clear() likh kar Enter, phir F5.

🗂️ Sirf ek app tab

8081 wala page ek hi tab mein kholo. Do tab khule hon to dono ki web screens ek hi storage use karti hain aur testing gadbad ho jaati hai.

🔒 Live data safe

Preview asli Firebase se data padhta hai, lekin kuch likhta nahi — testing se live data nahi badalta.

🎞️ Animations

Home ki tiles ka "upar uthkar aana" wala animation browser mein band rakha hai (browser mein wo tiles ko ek-doosre par chadha deta tha). Phone par wo chalta hai.

7Kya browser mein nahi chalta

Ye cheezein sirf phone par test hoti hain (dekho EXPO-PHONE-GUIDE.html):

CheezBrowser mein kya hota hai
NotificationsNahi aate; permission "granted" maan li jaati hai
Google / Phone OTP loginNahi hota (native hai)
Audio/Book download, PDFNahi hota (phone ka storage chahiye)
App UI Size, lock-screen controlsNahi hota
FontsHindi Noto font phone jaisa; English ke liye Windows ka font, isliye halka farak ho sakta hai
