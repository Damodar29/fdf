1Ye kaise kaam karta hai

App ke do hisse hain: native (Java/Kotlin/C++ — Firebase, audio, notifications, WebView) aur JavaScript (saari screens, design, logic). Native hissa build karne mein time lagta hai; JavaScript ko build ki zaroorat hi nahi.

Debug app (Expo "dev build") mein native hissa phone par install hota hai, aur JavaScript PC par chal rahe Metro se aata hai. Isliye src/ mein koi file save karo — phone par turant badlav.

Code save→Metro (PC, 8081)→USB / WiFi→Phone par app reload
✅

Build time ki asli bachat yahi haiDebug app sirf ek baar (aur native badlav par) banti hai. Roz ke UI kaam ke liye APK banana hi nahi padta.

2Zaroori niyam

🚫

Asli app ko kabhi mat chhunaSirf com.cpbs.bhajans.rntest ("Prem Bhakti RN") install / uninstall karna. com.cpbs.bhajans asli Play Store app hai — uska data chala jaayega.

⚠️

PC par APK double-click mat karnaIs computer par .apk BlueStacks se khulti hai. APK sirf phone mein jaati hai (Android Studio Run, ya scripts\install-release-on-phone.cmd).

Gradle 9.3.1 aur JDK 17 hi rehne do. Android Studio upgrade ka popup dikhaye to mana kar do.

3Pehli baar: debug app phone par daalna

  1. Phone USB se jodo (Developer options → USB debugging ON). Check:
    "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" devices
    List mein phone ka serial aur device likha aaye to theek. unauthorized aaye to phone par "Allow USB debugging" dabao.
  2. Android project taaza karo (sirf jab native cheez badli ho, ya pehli baar):
    cd /d C:\rn\mobile && npx expo prebuild --platform android
  3. Debug app build + install — tareeka A (Android Studio): C:\rn\mobile\android kholo → Build Variants → :app → debug → upar device mein apna phone → hara ▶ Run.
  4. Tareeka B (bina Studio, ek command): sirf ek phone juda ho tab:
    cd /d C:\rn\mobile\android && gradlew.bat installDebug
    Kitna time? Pehli baar 20–30 minute (C++ hissa banta hai). Uske baad native badlav par kuch hi minute, kyunki Gradle ka cache kaam aata hai.

4Roz ka kaam

  1. Metro chalao — ye file double-click karo aur window khuli rehne do:
    C:\rn\mobile\scripts\start-metro.cmd
    Ye kya karta hai? adb reverse tcp:8081 tcp:8081 (phone ka localhost:8081 PC tak pahunchta hai), phir npx expo start --dev-client.
  2. Phone par "Prem Bhakti RN" kholo. Wo khud Metro se jud jaati hai. Pehli baar bundle banne mein ~1 minute.
  3. Code badlo — src/ mein file save karte hi phone par update (Fast Refresh).
  4. Pura reload: Metro window mein r. Dev menu: phone hilao, ya Metro window mein m.
💡

Debug app thodi dheemi chalti hai (JS debug mode mein hota hai). Animation ya speed ka asli feel dekhna ho to release APK banao (section 8).

5Bina cable (same WiFi par)

  1. PC aur phone ek hi WiFi par hon. Metro chalao:
    cd /d C:\rn\mobile && npx expo start --dev-client
  2. Phone par app kholo → "Enter URL manually" → Metro window mein dikha http://192.168.x.x:8081 daalo.
  3. Windows Firewall poochhe to Private network par Allow karo.

7Build jaldi kaise ho

Project mein ab ye settings pehle se lagi hain (plugins/withBuildSettings.js, plugins/withTestBuild.js):

📱 Sirf ek CPU type

Test build sirf arm64-v8a (aapka Galaxy M55) ke liye banta hai. Pehle 4 type bante the — C++ ka kaam ~4 guna tha.

🗃️ Gradle cache + 4 GB

Pichhle build ka kaam dobara use hota hai; Gradle ko zyada memory milti hai.

🧹 --clean kam chalao

npx expo prebuild --clean sab naya banwata hai. Bina --clean wala kaafi hai jab tak koi ajeeb error na aaye.

🖥️ PC ko halka rakho

Build ke time Chrome ke bahut tabs / doosre heavy apps band rakho (16 GB RAM, 4-core CPU par fark padta hai).

ℹ️

Sabse badi bachat: roz ke UI kaam ke liye build hi mat karo — debug app + Metro (section 4), ya browser preview (WEB-PREVIEW-GUIDE.html).

8Release APK kab banana hai

Release APK mein JS andar hi hota hai — Metro ki zaroorat nahi, aur speed asli app jaisi. Isse banao jab: poora test round ho, ya kisi aur ko app deni ho.

cd /d C:\rn\mobile\android && gradlew.bat assembleRelease
APK yahan banti hai: android\app\build\outputs\apk\release\app-release.apk. Phone par daalne ke liye scripts\install-release-on-phone.cmd. Release build ab code ko chhota (R8) bhi karta hai, isliye APK pehle se kaafi chhoti hai.

Poori APK guide: ANDROID-BUILD-GUIDE.html.
